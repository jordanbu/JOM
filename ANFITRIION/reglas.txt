1️⃣ PRINCIPIO FUNDAMENTAL
El espacio es el principal recurso visual de JOM.
 Si algo se ve mal, casi siempre es spacing, no color.
En JOM:
el espacio ordena


el espacio jerarquiza


el espacio da sensación premium


Nunca se “acomoda a ojo”.

2️⃣ SISTEMA BASE DE ESPACIADO (NO NEGOCIABLE)
📏 Sistema oficial
8pt Spacing System
Todos los espacios deben ser múltiplos de:
4px / 8px / 16px / 24px / 32px / 48px / 64px

❌ No usar valores arbitrarios (13px, 19px, 27px, etc.).

3️⃣ ESTRUCTURA GENERAL DE PÁGINA (DESKTOP WEB)
🖥️ Canvas
Desktop base: 1440px


Max content width: 1120–1200px


Contenido centrado



📐 Márgenes laterales
Desktop: 24–32px


Mobile: 16px


Nunca contenido “pegado” al borde.

.

📐 Layout & Margins 
Principio general
El producto NO utiliza un único margen global.
 El sistema define tipos de contenedor según la densidad de información y el objetivo de la interfaz, garantizando consistencia visual sin sacrificar usabilidad.

1️⃣ Container · STANDARD
Uso: Interfaces de lectura, decisión y foco principal.
Aplica a:
Detalle de anuncio


Checkout / pago


Login / registro


Páginas informativas y de perfil simple


Reglas técnicas:
max-width: 1200px


padding-left / right: 32px


Ritmo visual relajado


Mayor aire lateral


Objetivo UX: claridad, comodidad de lectura y jerarquía visual.

2️⃣ Container · DENSE
Uso: Interfaces con alta carga de información funcional.
Aplica a:
Mensajería (host / guest)


Reservas y listados


Panel del anfitrión


Configuración de cuenta


Tablas y vistas administrativas


Reglas técnicas:
max-width: 1320px – 1360px


padding-left / right: 24px


Mayor aprovechamiento del espacio horizontal


No se reduce tipografía, solo se ajusta layout


Objetivo UX: maximizar información visible sin sensación de saturación.

3️⃣ Container · FULL (uso controlado)
Uso: Casos especiales de vistas divididas o data-heavy.
Aplica a:
Split view (mensajes + panel lateral)


Calendarios complejos


Tablas extensas con filtros


Reglas técnicas:
width: 100%


padding-left / right: 16px – 24px


Uso obligatorio de:


columnas claras


divisiones visuales


fondos diferenciados

Background: #4A45B0
Cursor: pointer
Transition: 150–200ms ease
❌ No scale grande
❌ No bounce
❌ No glow

🖱️ Botón Secundario
Background: #F8F9FC
Border permanece

🖱️ Links
Subrayado sutil
Color hover: #4A45B0

🖱️ Cards (clickables)
Shadow ligeramente más visible
No mover posición
No scale > 1.01

3️⃣ FOCUS STATES (ACCESIBILIDAD)
⌨️ Inputs / Selects
Border: #5B55C8
Focus ring sutil (2px máx)
Nunca glow fuerte
📌 El focus debe ser visible pero elegante.

⌨️ Botones
Outline fino en UI Primary
No cambiar tamaño

4️⃣ ACTIVE / PRESSED STATES
Botones
Background se oscurece ligeramente
Duración corta (100–150ms)
📌 Sensación de “click real”, no animación.

5️⃣ LOADING STATES (MUY IMPORTANTE)
⏳ Botón en loading
Spinner inline
Texto puede ocultarse o mantenerse
Botón deshabilitado
❌ No overlays gigantes
❌ No loaders full screen si no es crítico

⏳ Page loading
Skeletons (preferido)
Nunca spinner eterno sin feedback

Text: #9CA3AF
